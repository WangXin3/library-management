# library-management
# 图书管理系统
技术栈：
* Jdk1.8
* SpringBoot 2.6.1
* MyBatisPlus
* SpringSecurity
* Redis
* MySQL5.7
* ...

运行前置条件：Redis、Mysql5.7、Jdk1.8(基于1.8开发，其他版本自测)

运行步骤：
1. 创建数据库名为library_management、运行本项目init.sql文件。
2. 启用redis
3. 修改application.yaml，数据库连接信息，账号密码。redis连接信息，密码。
4. 运行项目。

对应前端项目地址：https://github.com/WangXin3/library-management-front
